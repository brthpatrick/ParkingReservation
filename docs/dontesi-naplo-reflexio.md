## Reflexió

A fejlesztés során a legnagyobb kihívás a Docker környezet összeállítása volt: a Visual Studio által generált Api projekt véletlenül class library sablonnal jött létre webapi helyett, ami hiányzó Program.cs és Controllers mappa formájában okozott zavart, és ezt a projekt törlésével és helyes sablonnal való újralétrehozásával oldottam meg. Hasonlóan tanulságos volt a Swagger UI eltűnése Docker környezetben, aminek oka az volt, hogy a konténer alapból Production módban fut, és a UseSwaggerUI() hívás Development-hez volt kötve. A repository implementáció és az interfész közötti eltérés (hiányzó metódusok, hiányzó interfész-implementáció) egy építési hibát is okozott, amit a két fájl egymás mellé állításával sikerült beazonosítani. A legnagyobb tanulság, hogy Docker Compose-ban a szolgáltatások közötti függőséget nem elég depends_on-nal jelezni, healthcheck is szükséges a megbízható induláshoz. Az opcionális parkolóhely-típus funkció hozzáadása jól mutatta, hogy a réteges architektúra kifizetődik: az új szabályokat csak a Service rétegben kellett hozzáadni, a repository és a kontroller réteg alig változott.
